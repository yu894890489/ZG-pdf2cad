## 处理策略

### 叶节点（最小编码单元）
每张部段图/横担图 = 一个叶节点
- 输入: DXF 干净几何(过滤后) + PDF OCR(文字/明细表)
- 输出: 该段/该横担的杆系子模型(JSON)
- 质检: 该段碰撞检查

### 拼凑（自底向上）
1. 底层: 每个叶节点独立提取
2. 中层: 段间按标高/截面拼接（上段顶=下段底）
3. 顶层: 全塔装配（001 正视图校验闭合）
4. 验证: 正视图投影比对 + 碰撞检查

### 以 001 为权威基准
- 腿线拟合(z→hw) = 全塔轮廓
- 横担层标高 = 横担 z 定位
- 段组合 = 变体管理
- 正视图比对 = 最终验收
